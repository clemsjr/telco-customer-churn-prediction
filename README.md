Telco Customer Churn Prediction

A machine learning project that predicts whether a telecom customer is likely to leave the company.

Tools: Python, Pandas, Scikit-learn, Streamlit

Model: Decision Tree Classifier

Performance: Improved F1-score from 0.559 to 0.585 through hyperparameter tuning.

Features:

- Data cleaning and exploratory data analysis
- Model training and evaluation
- Hyperparameter tuning
- Interactive Streamlit web application

Purpose: Built as part of my learning journey in data analytics and machine learning.
